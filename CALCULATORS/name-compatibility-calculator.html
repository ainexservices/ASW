How Name Compatibility Is Calculated

Numerology systems assign numerical values to letters. The resulting name values can then be reduced and compared according to the chosen system.

🔤
Letter Values

Each alphabetic character receives a numerical value according to the selected numerology system.

🔢
Root Number

The combined name value is reduced to a single digit for traditional comparison.

❤️
Comparison

The two root numbers are compared to create a simple compatibility interpretation.

ℹ️ Important Note

Name compatibility is a traditional numerology concept and is not scientifically established. A compatibility score should not be treated as a prediction of relationship success. Healthy relationships depend on communication, trust, respect and many real-world factors.
